## Ключевые возможности

- **Встроенный обход блокировок ТСПУ/DPI (РФ & СНГ)**:
  - Прямой доступ к API `osucollector.com` без сторонних утилит (за счёт встроенной сегментации `TCP SNI Split` и DoH `cloudflare-dns.com` / `dns.google`).
  - Программа запускается и открывает каталог коллекций на любом ПК без необходимости настраивать VPN, GoodbyeDPI или zapret.
- **Поддержка двух платформ osu!**:
  - **osu!lazer**: автоматический импорт через IPC, прямая синхронизация коллекций в `client.realm`, а также режим сохранения в `.zip` архив с предупреждением для обхода лимита игры (~350 карт в день).
  - **osu!stable**: загрузка напрямую в папку `Songs` с автогенерацией и обновлением файла `collection.db`.
- **Официальная интеграция с osu! OAuth**:
  - Вход в аккаунт osu! через браузер (`localhost:7270/callback`).
  - Скачивание оригинальных карт напрямую с официальных серверов `osu.ppy.sh` без задержек.
- **Интеллектуальная сеть зеркал с автодокачкой**:
  - Поддержка источников: **osu.ppy.sh (Official)** ➔ **beatconnect.io** ➔ **catboy.best** ➔ **osu.direct** ➔ **nerinyan.moe** ➔ **sayobot**.
  - Автоматическая докачка файлов по частям (`HTTP Range`) при разрывах соединения провайдером.
  - Мгновенное переключение при лимитах (`429 TooManyRequests`) или отсутствии карты на отдельном сервере.
- **Полноценный каталог внутри программы**:
  - Поиск по названию, тегам и стилям (`stream`, `aim`, `farm`, `tech`, `dt`, `relax`...).
  - Топ коллекций за всё время, месяц, неделю и день.
  - Анализ локальной библиотеки: программа определяет, какие карты уже установлены в игре, чтобы не скачивать их повторно.
- **100% Self-Contained**:
  - Один автономный `.exe` файл без сторонних зависимостей. Не требует отдельной установки .NET SDK или Runtime.

## Быстрый старт

### 1. Скачивание
Перейдите в раздел [Releases](https://github.com) и скачайте исполняемый файл `CHRONOS.exe`.

### 2. Запуск
Запустите `CHRONOS.exe`. Программа автоматически обнаружит установленные версии **osu!lazer** и **osu!stable**, а также просканирует уже имеющиеся карты, чтобы не загружать дубликаты.

### 3. Авторизация osu! (опционально)
В главном меню выберите пункт `Войти в аккаунт osu!` — в браузере откроется официальная страница авторизации osu!. Нажмите **Authorize**, и CHRONOS сможет скачивать карты напрямую с официального сайта osu!.

## Консольный режим (CLI / Автоматизация)

CHRONOS поддерживает работу через командную строку для пакетной загрузки:

```bash
# Скачать коллекцию по номеру в osu!lazer
CHRONOS 44

# Скачать коллекцию по ссылке в osu!stable
CHRONOS https://osucollector.com/collections/1234 --stable

# Скачать без видео в 8 потоков
CHRONOS 44 --no-video --threads 8

# Не качать карты, а только создать коллекцию в игре из уже имеющихся
CHRONOS 44 --collection-only

# Задать своё название коллекции в игре
CHRONOS 44 --collection-name "My Practice Stream Maps"
```

### Доступные флаги CLI:

| Флаг | Описание |
| :--- | :--- |
| `-l`, `--lazer` | Использовать osu!lazer |
| `-s`, `--stable` | Использовать osu!stable |
| `-z`, `--zip` | Скачать карты в отдельный .zip архив (обход лимита lazer на 350 карт/день) |
| `-t`, `--threads N` | Количество параллельных потоков скачивания (1–16) |
| `-nv`, `--no-video` | Скачивать карты без фонового видео (быстрее и экономит место) |
| `-co`, `--collection-only` | Создать коллекцию без скачивания недостающих карт |
| `-nc`, `--no-collection` | Только скачать карты в игру, не создавая коллекцию |
| `-c`, `--collection-name <имя>` | Указать своё название для коллекции в игре |
| `-f`, `--force` | Принудительно перекачать все карты коллекции заново |
| `-o`, `--save-dir <папка>` | Папка сохранения карт или .zip архива |
| `--list-collections` | Вывести список всех коллекций в выбранной игре |
| `-h`, `--help` | Показать справку по командам |

## Сборка из исходников

Для сборки проекта требуется установленный [.NET 8.0 SDK](https://dotnet.microsoft.com/download/dotnet/8.0):

```bash
# Клонировать репозиторий
git clone https://github.com/your-username/CHRONOS.git
cd CHRONOS

# Собрать готовый автономный single-file исполняемый файл
dotnet publish CHRONOS.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:EnableCompressionInSingleFile=true -o ./publish
```

После выполнения команды в папке `./publish` появится готовый автономный `CHRONOS.exe`.

## Безопасность и хранение данных

- Все настройки и история загрузок сохраняются в изолированной системной папке:
  `%APPDATA%\CHRONOS\` (`chronos.json`, `history.txt`, `history_stable.txt`).
- Пароли от аккаунта osu! нигде не сохраняются — используется только стандартный OAuth2 токен доступа с правами `public identify`.
- Перед любым изменением коллекций в игре CHRONOS создаёт локальную резервную копию базы (`collection.db.bak` / `client.realm.bak`).
